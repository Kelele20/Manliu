# 漫流使用与开发说明（v0.3.2 预发布版）

## 版本与升级

- [下载 v0.3.2 预发布版 APK](https://github.com/Kelele20/Manliu/releases/tag/v0.3.2)。[v0.3.0 旧版](https://github.com/Kelele20/Manliu/releases/tag/v0.3.0)仍可在 Releases 中获取。
- v0.3.2 发布页说明该 APK 与 v0.3.0 使用相同签名，可直接覆盖安装。升级前建议先从首页菜单备份重要图集；不要先卸载旧版，卸载会清除应用内图片和数据库。
- v0.3.2 是预发布体验版。拖动手势和覆盖升级流程尚未在实体安卓设备验证。仓库为私有仓库，下载需要有权限的 GitHub 账号。
- 开发签名密钥 `manliu-dev-key.keystore` 单独保存在私人位置，不在 Git 仓库或 Release 中。使用不同签名的 APK 不能覆盖安装。要用同一签名构建，把原密钥文件放在项目根目录。

## 导入图片

1. 点击「新建图集」→「添加图片」→「从文件夹选择 · 全选/排序」，选择**含图片的子文件夹**。
2. 预览中按「全选」或逐张勾选。可按名称自然升序（如 1、2、10）、名称降序或最近修改时间排序；一次最多选 10000 张。点击「导入」后会检查已知图片大小及可用空间，再启动后台导入。
3. 图集页显示已处理、成功和失败张数。可以暂停、继续或取消；已导入的图片会保留。点「失败清单」查看原因，任务完成后可点「重试失败项」。系统中断时重新打开图集点「继续导入」或「尝试恢复」。对于文件提供方未报告大小的图片，预估空间可能偏低；空间不足时清理空间再继续。

「从相册选择」「从文件选择」适合导入零散图片，每次在应用侧最多接收 100 张；相册系统选择器的实际数量限制取决于设备。每张图片最大 100 MB。文件夹模式只读取所选文件夹的当前层级，不递归读取子文件夹。若图片来自云盘等文件提供方，导入过程中须保持其可访问。

Android 11 及以上限制普通应用直接读取 `Android/data`，系统选择器也不能直接选 `Download` 根目录。可先用手机自带文件管理器将原图**复制**到 `Download/漫流待导入` 等子文件夹，再选该子文件夹。漫流会再复制到应用专属存储，确认导入成功后可自行清理中转文件。删除手机里的原图不会同步删除漫流副本，反过来也一样。

## 阅读与管理

- 长按右侧「≡」拖动图集或图片，靠近屏幕边缘可自动滚动；松手后保存顺序。图集页右上角菜单仍可按文件名升序或降序排序。点「批量选择」→「全选」→「删除所选」可删除多张应用内副本，原图不受影响。
- 首页点击图集卡片进入整理；点击卡片内「开始阅读／继续阅读」直接进入阅读页。图集页也可点击「开始阅读」。向上滑动连续阅读，点画面显示工具栏，点右上页码跳到指定页。
- 阅读进度自动保存。图片拖动、按文件名排序和删除后会尽量保留正在阅读的图片；删除当前页时会跳到附近页面。旧版章节标记仍保存在旧数据库中，但 v0.3.2 不再显示章节或目录入口。

## 备份与恢复

首页右上角「备份和恢复」菜单可备份全部图集或恢复备份；单个图集右上角菜单可备份该图集。备份扩展名为 `.manliu`，可以保存到系统文件管理器、云盘或移动硬盘，内容包括图集、图片顺序和阅读进度。恢复后会作为新图集加入，不覆盖现有图集。旧版含章节标记的备份仍可恢复图片和顺序，但章节标记不会恢复。

恢复仅支持漫流生成的 `.manliu` 文件，不支持普通 ZIP/CBZ 漫画包。图片和数据库位于应用专属目录；卸载会删除它们。请把备份保存到应用外的位置。自动备份未开启。备份或恢复大量图片时应留出足够空间并等待任务完成；取消备份可能留下不完整文件，可在文件管理器中删除。

## 从源码构建

安装 JDK 17 与 Android SDK 35，在 Android Studio 打开仓库根目录，或执行：

```bash
./gradlew assembleDebug
```

Windows 用 `.\gradlew.bat assembleDebug`。APK 在 `app/build/outputs/apk/debug/app-debug.apk`。最低 Android 8.0，目标 Android 15。项目使用 Kotlin、Compose、Room 和 Coil；应用未声明自身网络权限。

GitHub Actions 在 Pull Request 上执行 `assembleDebug`，不运行单元测试或 Android 仪器测试。v0.3.2 的拖动手势与升级安装尚未在实体设备验证。
