# 漫流使用与开发说明（v0.4.2）

## 版本与升级

- 本文档对应 **v0.4.2**（`versionCode = 11`）。
- 升级安装时推荐从首页右上角菜单导出备份重要图集。**不要先卸载旧版**，直接覆盖安装即可保持数据库和导入图片不丢失。
- 本仓库基于 Apache 2.0 协议开源，可在 GitHub Releases 页面直接下载预构建 APK。
- 开发签名密钥 `manliu-dev-key.keystore` 属于私人密钥，不在公开 Git 仓库中。使用不同签名构建的 APK 无法在手机上覆盖安装。

## 导入图片

漫流支持三种便捷的图片导入方式：

### 1. 从 ZIP / CBZ 漫画压缩包导入

漫画爱好者与长篇条漫最常用的方式：

1. 在图集详情页点击「添加图片」→「从 ZIP / CBZ 压缩包导入」；
2. 选择本地存储中的 `.zip` 或 `.cbz` 压缩包文件；
3. 前台服务先记录任务，再在后台流式解压，过滤 `__MACOSX`、隐藏目录、隐藏文件与非图片条目；离开图集页面或切换到阅读器后仍继续处理；
4. 按**完整章节路径自然排序**，例如 `第2章/1.jpg → 第2章/2.jpg → 第10章/1.jpg`，避免不同章节的同名页交错入库；
5. 解压完成后统一加入图片导入队列。解压期间显示「正在解压漫画包」及已找到的图片数量，使用不定进度条；入库期间显示准确总数及成功、失败数量。

*支持的压缩包内图片格式*：`jpg`, `jpeg`, `png`, `webp`, `gif`, `bmp`, `heic`, `heif`, `avif`。

#### 漫画包限额

| 限制 | 规则 |
|------|------|
| 有效图片数量 | 每个漫画包最多 10,000 张 |
| 单个解压文件 | 不超过 100 MiB，非图片条目也受此限制 |
| 累计解压量 | 不超过开始解压时的可用空间减去 64 MiB；被过滤的条目也计入解压预算 |
| 剩余空间 | 每次写入前检查，至少预留 64 MiB 可用空间 |

超过限额、空间不足或压缩包解析失败时，任务会暂停并显示原因，清理尚未完成解压的暂存文件；该漫画包在解压完成前不会开始图片入库。空间不足可清理后继续；图片数量或单文件大小超限需要取消任务、拆分或调整压缩包后重新选择。

#### 暂停、继续与清理

- **解压阶段暂停**：停止解压并清理未完成的暂存文件；点击「继续导入」会从原压缩包重新解压，需要原文件及其读取授权仍可访问。
- **入库阶段暂停**：保留已入库图片及尚待处理的暂存图片；继续时处理未完成条目，失败项可单独重试并按原始顺序插入。
- **取消任务**：停止后续处理并清理该任务的暂存目录，已经导入的图片保留。
- **删除图集**：停止对应导入任务，删除图集内图片和相关导入暂存目录；清理与正在进行的解压、复制协调执行，离开页面不会中断清理。

### 2. 按文件夹批量导入

适合大量图片的文件夹批量扫描导入，**单次最多支持 10,000 张**：

1. 点击「添加图片」→「从文件夹选择 · 全选/排序」，选择目标图片文件夹；
2. 预览列表中可按「全选」或逐一勾选；
3. 支持按名称自然升序（1 → 9）、名称降序（9 → 1）或最近修改时间排序（排序在后台线程异步执行，不阻塞界面）；
4. 点击「导入」后系统会核查空间预估并启动后台导入服务；
5. 图集页导入进度卡片实时同步已处理、成功与失败数量，支持随时暂停、继续或取消。

### 3. 从系统相册或文件管理器选择

在图集页点击「添加图片」，选择「从相册选择」或「从文件选择」：

- **单批次最多 100 张**；
- 多选图片会先暂存到应用目录，随后通过前台服务逐张入库；
- 离开当前页面或切换至阅读器时，后台导入任务不受影响。

### 导入注意事项

| 维度 | 说明 |
| :--- | :--- |
| **层级支持** | 目前文件夹导入仅读取所选文件夹当前层级，不递归子文件夹 |
| **系统限制 (Android 11+)** | 系统限制直接选择 `Android/data` 或 `Download` 根目录。建议先用系统文件管理器复制到 `Download/待导入` 等子目录 |
| **独立存储** | 导入漫流的图片会完整复制在应用专属私有目录中，删除手机相册或原文件不会影响漫流内的阅读 |
| **断点与重试** | 暂停任务可点「继续导入」，失败图片可点「重试失败项」；漫画包解压阶段会重新解压，入库阶段按未完成条目续传，源文件或授权失效时需要重新选择 |

## 阅读与管理

### 沉浸式阅读与手势交互

- **连续向下滑动**：单页图片自动上下拼接，提供无缝纵向长条漫阅读体验。
- **双指缩放（Pinch-to-zoom）**：阅读器支持双指自由捏合放大（1x ~ 4x），方便放大查看分镜细节与精细对白。
- **双击放大与重置**：双击画面可在 1x 与 2.2x 之间快速切换；放大模式下工具栏提供「重置 1x」按钮。
- **自由平移（Pan）**：放大模式下智能解耦列表滚动，支持单指/双指在画面内自由拖拽平移。
- **屏幕常亮（Keep Screen On）**：进入阅读器后自动保持屏幕常亮不熄屏，退出阅读器后恢复系统默认设置。
- **深色与纯黑背景模式（AMOLED Black）**：轻触画面唤出工具栏，点击「深黑/浅米」按钮可一键切换背景底色，夜间阅读更舒适护眼。
- **精确页码跳转**：点击工具栏右上角页码指示器，可输入指定页码立即跳转。
- **进度保存机制**：阅读器基于稳定图片 ID 保存当前浏览进度，在图集前部插入新图片后依然能够精准恢复到原先的画面。

### 排序与整理

- **极致平滑长按排序**：
  - 在图库首页或图集详情页中，长按右侧「≡」手柄即可上下拖动；
  - 采用**相对位移数学补偿算法**，彻底消除了卡片跨项交换时的单帧抽搐跳跃；
  - 被挤开的相邻卡片应用了 Compose **弹性平滑滑移动画（Spring Animation）**，让位自然流畅；
  - 优化了数据持久化同步，松手后无任何回弹闪烁。
- **按文件名自动排序**：图集菜单提供一键按文件名自然升序（1 → 9）或降序（9 → 1）排列。
- **批量管理与删除**：支持多选图片后一键批量删除应用内副本，不影响系统原图。

## 备份与恢复

### 操作入口

| 操作 | 位置入口 |
|------|----------|
| **备份全部图集** | 首页右上角菜单 →「备份全部图集」 |
| **备份单个图集** | 图集详情页右上角菜单 →「备份这个图集」 |
| **恢复漫流备份** | 首页右上角菜单 →「恢复漫流备份」 |

### 规格与安全机制

- 备份文件为 `.manliu` 格式（无压缩 ZIP + `manifest.json` 元数据）。
- **先验后写机制**：在执行导出前，系统会预先校验图集数、图片数与总容量，全部通过后才开启输出流，杜绝生成损坏的半截文件。
- **恢复不覆盖原则**：恢复备份时会将备份包内的图集作为新图集创建，不会冲掉当前现有数据。

## 从源码构建

### 环境要求

- JDK 17
- Android SDK 35
- Gradle 8.7（由项目自带 Wrapper 自动下载）

### 构建命令

```bash
# 执行单元测试并构建 Debug 安装包
./gradlew :app:testDebugUnitTest :app:assembleDebug

# 构建 Release 安装包（已启用 R8 混淆与资源压缩）
./gradlew :app:assembleRelease
```

Debug 产物路径：`app/build/outputs/apk/debug/app-debug.apk`

> **签名说明**：项目根目录存在 `manliu-dev-key.keystore` 时，Debug 构建使用该密钥；不存在时使用 Android 默认 debug 签名。覆盖安装要求新旧 APK 使用相同签名。当前 Release 构建未配置签名，`assembleRelease` 生成未签名 APK，安装前需另行签名；放入开发密钥不会自动为 Release 配置签名。

> **注意**：Release 构建已启用 R8 代码混淆（`isMinifyEnabled = true`）和资源压缩（`isShrinkResources = true`），ProGuard 规则文件为 `app/proguard-rules.pro`，其中保留了 Room 数据库实体类和 DAO。

## 自动化测试体系

项目包含 **31 项 JVM 自动化测试**，其中 12 项使用 Robolectric 验证真实 Room、前台服务及 Compose 交互，无需启动模拟器：

| 测试类 | 项数 | 覆盖要点 |
|--------|------|----------|
| `ArchiveLimitsTest` | 5 | 1,000 图集上限、200,000 图片上限、64 MiB 清单上限、100 MiB 单图上限及先验后写验证 |
| `ImportOrderingTest` | 4 | 重试插入空隙位置、暂停恢复续传、新任务追加、用户重排后插入点计算 |
| `ReaderProgressTest` | 2 | 插入新增图片后阅读进度维持、动态页面列表更新 |
| `ArchiveParserTest` | 4 | ZIP/CBZ 图片识别过滤、隐藏目录排除、完整章节路径自然排序 |
| `ArchiveExtractionBudgetTest` | 4 | 图片数量、单文件大小、累计解压量及剩余空间边界 |
| `ArchiveImportIntegrationTest` | 10 | 真实入库顺序、超限清理、暂停恢复、取消及删除时的并发处理 |
| `ImportInteractionTest` | 2 | 解压期间离开页面仍完成导入、拖拽自动滚动时保持卡片位置 |
