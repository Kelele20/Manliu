# 漫流使用与开发说明（v0.3.3）

## 版本与升级

- [下载 v0.3.3 正式版 APK](https://github.com/Kelele20/Manliu/releases/tag/v0.3.3)。[v0.3.0 旧版](https://github.com/Kelele20/Manliu/releases/tag/v0.3.0)仍可在 Releases 中获取。
- v0.3.3 与 v0.3.2 使用相同签名，可直接覆盖安装。升级前建议先从首页菜单备份重要图集；**不要先卸载旧版**，卸载会清除应用内图片和数据库。
- 仓库为私有仓库，下载需要有权限的 GitHub 账号。
- 开发签名密钥 `manliu-dev-key.keystore` 单独保存在私人位置，不在 Git 仓库和 Release 中。使用不同签名的 APK 不能覆盖安装。要用同一签名构建，把原密钥文件放在项目根目录。

## 导入图片

### 按文件夹批量导入

这是导入大量图片的推荐方式，**一次最多 10,000 张**。

1. 点击「新建图集」→「添加图片」→「从文件夹选择 · 全选/排序」，选择**含图片的子文件夹**。
2. 预览中按「全选」或逐张勾选。可按名称自然升序（2 在 10 前）、名称降序或最近修改时间排序。点击「导入」后会检查已知图片大小及可用空间，再启动后台导入。
3. 图集页的导入进度卡显示已处理、成功和失败张数。可暂停、继续或取消；取消后已导入图片会保留。任务中断后重新打开图集，可点「继续导入」或「尝试恢复」。在「失败清单」查看错误原因，再点「重试失败项」；失败项会按原始导入顺序插入。

### 从相册或文件选择

在图集页点击「添加图片」，选择「从相册选择」或「从文件选择」。**每批最多 100 张**，超过部分需分批选择；相册系统选择器可能按设备进一步限制数量。单张图片不得超过 100 MiB。

多选图片需要先从系统选择器暂存到漫流的应用目录。若系统在暂存完成前终止任务，且重启后原 URI 授权已失效，对应图片会失败，需要重新选择。来自云盘等文件提供方的图片在暂存期间必须保持可访问。

### 导入注意事项

| 事项 | 说明 |
|------|------|
| **文件夹层级** | 只读取所选文件夹当前层级，不递归读取子文件夹 |
| **Android/data** | Android 11+ 限制直接读取 `Android/data`，系统选择器也不能直接选 `Download` 根目录 |
| **建议做法** | 先用手机自带文件管理器将原图**复制**到 `Download/漫流待导入` 等子文件夹，再选该子文件夹 |
| **图片独立** | 导入后的图片是副本，删除手机原图不影响漫流，反过来也一样 |
| **空间预估** | 文件提供方未报告大小时预估可能偏低，空间不足时先清理空间再继续 |
| **后台运行** | 多选任务通过前台服务持续处理，离开图集页或切换到阅读页后仍可运行 |

## 阅读与管理

### 阅读

- 首页点击图集卡片内的「开始阅读 / 继续阅读」直接进入阅读页，图集页也可点击「开始阅读」。
- 向上滑动连续阅读。**点击画面**显示工具栏，点右上页码可跳到指定页。
- 阅读页会**实时观察图集变化**：后台导入的新图片会自动显示出来。
- 阅读进度按稳定图片 ID 保存，插入新图片后仍尽量回到原页。

### 排序与整理

- **拖拽排序**：长按右侧「≡」手柄拖动图集或图片，靠近屏幕边缘自动滚动，松手后立即保存。
- **文件名排序**：图集页右上角菜单可按文件名升序（1 → 9）或降序（9 → 1）排列。使用自然排序算法，2.jpg 排在 10.jpg 前面。
- **批量删除**：点「批量选择」→「全选」→「删除所选」可删除多张应用内副本，手机原图不受影响。

### 章节说明

旧版章节标记仍保存在数据库中，但 v0.3.3 不再显示章节或目录入口。

## 备份与恢复

### 基本操作

| 操作 | 入口 |
|------|------|
| **备份全部图集** | 首页右上角菜单 →「备份和恢复」 |
| **备份单个图集** | 图集页右上角菜单 →「备份这个图集」 |
| **恢复备份** | 首页右上角菜单 →「恢复漫流备份」 |

### 备份内容

备份文件扩展名为 `.manliu`，包含：
- 图集信息（标题、顺序）
- 所有图片文件
- 图片排列顺序
- 阅读进度

### 注意事项

- **恢复会新增图集**，不覆盖现有内容。
- 仅支持漫流生成的 `.manliu` 备份，**不支持**通用 ZIP/CBZ 漫画包。
- 旧版备份中的图片和顺序可以恢复，章节标记不会恢复。
- 备份保存位置建议选择应用外的位置（如系统文件管理器、云盘、移动硬盘）。卸载应用会删除应用内数据。
- 自动备份尚未实现，请定期手动备份。

### 容量限制

创建和恢复备份采用相同上限（导出前验证，不会写入不完整文件）：

| 限制项 | 上限 |
|--------|------|
| 图集数量 | 1,000 个 |
| 图片数量 | 200,000 张 |
| 备份清单 | 64 MiB |
| 单张图片 | 100 MiB |

## 从源码构建

### 环境要求

| 要求 | 版本 |
|------|------|
| JDK | 17 |
| Android SDK | 35 |
| Gradle | 通过 Wrapper 自动下载 |

### 构建命令

```bash
# macOS / Linux
./gradlew :app:testDebugUnitTest :app:assembleDebug

# Windows
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

APK 输出路径：`app/build/outputs/apk/debug/app-debug.apk`

也可以在 Android Studio 打开项目根目录直接构建。

### 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Kotlin | 2.0.21 | 编程语言 |
| Jetpack Compose | BOM 2024.10.01 | UI 框架 |
| Room | 2.6.1 | 本地数据库 |
| Coil | 2.7.0 | 图片加载 |
| KSP | 2.0.21-1.0.25 | Room 注解处理 |
| AGP | 8.6.1 | Android 构建插件 |

应用未声明自身网络权限，最低支持 Android 8.0，目标 Android 15。

## 测试

### JVM 单元测试（11 项）

| 测试类 | 测试项 | 覆盖范围 |
|--------|--------|----------|
| `ArchiveLimitsTest` | 5 | 图集/图片数量上限、清单/图片大小限制、先验后写机制 |
| `ImportOrderingTest` | 4 | 失败重试插入位置、暂停恢复、新任务追加、用户重排后重试 |
| `ReaderProgressTest` | 2 | 插入图片后进度保持、页面列表实时更新 |

### CI 流程

Pull Request 的 GitHub Actions 运行上述任务：单元测试 + Debug APK 构建。不运行 Android 仪器测试。

### 待验证场景

以下场景已经过用户真机试用但尚未逐项做设备验证：

- 多选导入期间离开页面、旋转和暂停后恢复
- 暂存期间进程终止和 URI 授权失效
- 导入过程中阅读、后台新增图片和失败重试后的阅读位置
- 备份后再恢复的完整往返流程
