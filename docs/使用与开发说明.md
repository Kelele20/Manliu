# 漫流使用与开发说明

## 文件位置

本仓库保存安卓项目源码与构建说明。`Manliu-v0.1.0-android.apk`、`manliu-dev-key.keystore` 和可下载的中文说明保存在原先的 Google Drive 文件夹中。签名密钥不要提交到 Git 仓库，也不要公开分享。

## 安装与阅读

1. 在安卓手机上下载 APK，打开并按系统提示安装。首次安装时，系统可能要求允许文件管理器安装应用。
2. 打开「漫流」，点击「新建图集」，输入名称后点击「添加图片」，从手机中选择图片。
3. 在图集中使用「上移」「下移」调整顺序，点击「开始阅读」。向上滑动屏幕继续往下看；点按画面可显示或隐藏工具栏。
4. 返回后再次打开图集，会从上次保存的位置继续阅读。

单次最多选择 100 张图片，更多图片可以分批导入；每张图片上限为 100 MB。图片会复制到应用专属空间，原图仍保留在手机里，因此会占用额外空间。

## 从源码构建

使用 Android Studio 打开仓库根目录，安装 JDK 17 和 Android SDK 35。在 Windows PowerShell 中运行：

```powershell
.\gradlew.bat assembleDebug
```

输出文件是 `app/build/outputs/apk/debug/app-debug.apk`。最低支持 Android 8.0。

若要让新版本覆盖已经安装的 v0.1.0，请先从私有文件夹取得 `manliu-dev-key.keystore`，放在仓库根目录后再构建。构建脚本会使用这把密钥；同时保持 `applicationId` 为 `com.kelele.manliu`。不要把密钥加入提交。

## 当前限制与验证

应用完全离线。卸载应用会清除导入的图集和阅读进度；目前没有备份导出、文件夹或 ZIP 导入、自动去白边。特别长或特别大的单张图片能否流畅显示取决于手机内存。

v0.1.0 已通过 Gradle 构建和 APK 签名检查，尚未在实际安卓手机上完成操作验证。
