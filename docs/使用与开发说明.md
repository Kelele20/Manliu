# 漫流使用与开发说明

## 文件位置

本仓库保存安卓项目源码与构建说明。最新 APK 在 GitHub 的 [v0.2.2 Release](https://github.com/Kelele20/Manliu/releases/tag/v0.2.2) 下载；v0.1.0 安装包、`manliu-dev-key.keystore` 和可下载的中文说明保存在原先的 Google Drive 私有文件夹中。签名密钥不要提交到 Git 仓库或 Release，也不要公开分享。

## 安装与阅读

1. 在安卓手机上下载 APK，打开并按系统提示安装。首次安装时，系统可能要求允许文件管理器安装应用。
2. 打开「漫流」，点击「新建图集」，输入名称后点击「添加图片」。需要全选和排序时点击「从文件夹选择 · 全选/排序」并选择含图片的文件夹；在预览中点击「全选」，可切换文件名升序、降序或最近修改优先，然后点击「导入」。相册中的图片也可以选「从相册选择」；散落在下载目录的图片可以选「从文件选择」。
3. 在图集中使用「上移」「下移」逐张调整顺序，或点右上角菜单按文件名批量升序、降序排序，然后点击「开始阅读」。向上滑动屏幕继续往下看；点按画面可显示或隐藏工具栏。
4. 返回后再次打开图集，会从上次保存的位置继续阅读。

v0.2.0 默认使用浅色主题，图集列表显示首张图片封面，应用图标是原创二次元少女插画。图集页右上角菜单可删除整个图集。

单次最多导入 100 张图片，文件夹超过 100 张时按钮显示「选前 100 张」；每张图片上限为 100 MB。数字文件名按自然顺序排列，如 1、2、10。文件夹预览只展示选中文件夹当前层级的图片，不包含子文件夹。图片会复制到应用专属空间，原图仍保留在手机里，因此会占用额外空间。文件来源若需联网下载，导入时请保持该文件来源可访问。

Android 11 及以上系统限制普通应用读取 `Android/data`，系统的「从文件选择」和「从文件夹选择」都不能直接进入此目录；「从文件夹选择」也不能直接选择 Download 根目录。如原图在 `Android/data`，请用手机自带文件管理器复制到 `Download/漫流待导入` 等**子文件夹**，再返回漫流选择那个子文件夹。确认导入成功后，可删除中转文件夹中的副本。

## 从源码构建

使用 Android Studio 打开仓库根目录，安装 JDK 17 和 Android SDK 35。在 Windows PowerShell 中运行：

```powershell
.\gradlew.bat assembleDebug
```

输出文件是 `app/build/outputs/apk/debug/app-debug.apk`。最低支持 Android 8.0。

若要让新版本覆盖已经安装的旧版本，请先从私有文件夹取得 `manliu-dev-key.keystore`，放在仓库根目录后再构建。构建脚本会使用这把密钥；同时保持 `applicationId` 为 `com.kelele.manliu`。不要把密钥加入提交。

## 当前限制与验证

应用不需要账户或自身网络权限。卸载应用会清除导入的图集和阅读进度；目前没有备份导出、整文件夹或 ZIP 一键导入、自动去白边。特别长或特别大的单张图片能否流畅显示取决于手机内存。

v0.2.2 已通过 Gradle 构建与 APK 签名检查，尚未在实际安卓手机上完成操作验证。
