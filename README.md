# 漫流（Manliu）

一款离线安卓条漫阅读器。创建图集、从系统相册批量导入图片、调整顺序，再通过连续向下滑动阅读。图片保持原本比例；阅读进度会自动保存。

[使用与开发说明](docs/使用与开发说明.md)

## 功能

- 创建、删除图集；多选导入 JPG、PNG、WebP 等系统能解码的图片。
- 在图集中使用上移、下移调整顺序，或删除单张图片。
- 竖向连续阅读，图片之间没有额外间距。点击画面显示或隐藏工具栏。
- 图集和阅读进度保存在手机本地，不需要账户或网络。

单次最多选择 100 张图片；更多图片可以分批导入。单张图片大小上限为 100 MB。导入时会复制一份图片到应用专属目录，因此原图移动或删除后仍可阅读；会占用相应的额外空间。卸载应用会删除应用内图集。当前版本尚未提供导出备份、文件夹/ZIP 导入、自动去白边；超大单张图片的解码能力取决于设备内存。

## 安装与使用

在安卓手机上打开 APK 并按系统提示安装。打开「漫流」后依次点击「新建图集」→「添加图片」→调整顺序→「开始阅读」。阅读时点按画面可隐藏或显示工具栏。

提供的 APK 为开发签名安装包。为将来覆盖安装新版本，保留单独提供的 `manliu-dev-key.keystore`，需要重新构建时将它放在项目根目录；构建脚本会使用同一把密钥。请不要公开分享该文件。若使用另一把密钥，安卓无法直接覆盖安装。

## 构建

使用 Android Studio 打开项目，安装 Android SDK 35 与 JDK 17。Windows PowerShell 执行 `.\gradlew.bat assembleDebug`，macOS/Linux 执行 `./gradlew assembleDebug`，安装 `app/build/outputs/apk/debug/app-debug.apk`。最低支持 Android 8.0（API 26）。

源码：Kotlin + Jetpack Compose + Room + Coil。图集元数据在 Room，图片文件在应用专属目录；系统照片选择器提供多图导入。
