# 漫流（Manliu）

离线安卓条漫阅读器。创建图集、导入图片、调整阅读顺序，然后连续向下滑动阅读；自动保存阅读位置。默认浅色界面，配有原创二次元少女图标。

[使用与开发说明](docs/使用与开发说明.md) · [下载 v0.3.2 预发布版 APK](https://github.com/Kelele20/Manliu/releases/tag/v0.3.2)（私有仓库，需登录授权）

## 功能

- **一次最多导入 10000 张**：选取图片文件夹，在漫流中全选或逐张选取，可按自然文件名升序、降序或修改时间排序。只读取当前层级；大批量导入在后台持续进行，支持暂停、继续、取消及失败清单和重试。导入前显示预估空间需求。
- **其他图片来源**：系统相册和「从文件选择」仍可使用，单次最多选择 100 张；系统选择器可能进一步限制相册可选数量。
- **整理和阅读**：长按手柄拖动图集或图片；图片也能按文件名排序、全选或批量删除。首页的「开始阅读／继续阅读」直接进入阅读页，阅读时点页码跳转。图集列表只查询封面与图片数量，不必加载图集里的所有图片。
- **备份和恢复**：在首页菜单备份全部图集，或在图集菜单备份单个图集；首页菜单可从漫流生成的 `.manliu` 文件恢复。备份包含图集、图片顺序和阅读进度；恢复会新增图集，不覆盖现有内容。旧版含章节的备份可恢复图片与顺序，但章节标记不再显示。
- **本地存储**：导入的图片复制到应用专属空间，原图移动或删除不会同步删除副本。图集删除和卸载应用会清除对应的应用内副本。

## 安装

[v0.3.2 预发布版](https://github.com/Kelele20/Manliu/releases/tag/v0.3.2)包含拖动排序和首页直达阅读等改动；[v0.3.0 旧版](https://github.com/Kelele20/Manliu/releases/tag/v0.3.0)也保留在 Releases。最低支持 Android 8.0。v0.3.2 发布页说明它与 v0.3.0 使用相同签名，可覆盖安装；升级前请备份重要图集，不要先卸载旧版。v0.3.2 尚未在实体设备验证拖动手势和升级流程，属于预发布体验版。仓库为私有仓库，下载需要有权限的 GitHub 账号。

进入「新建图集」→「添加图片」→「从文件夹选择 · 全选/排序」。Android 11 及以上不能通过系统选择器进入 `Android/data` 或直接选择 `Download` 根目录；可先用手机自带文件管理器把图片复制到 `Download/漫流待导入` 等子文件夹，再选择该子文件夹。通用 ZIP/CBZ 和递归导入子文件夹尚未实现；`.manliu` 是漫流自己的备份格式。

## 构建

Android Studio 打开本项目，安装 JDK 17 和 Android SDK 35；运行 `./gradlew assembleDebug`（Windows：`.\gradlew.bat assembleDebug`）。输出为 `app/build/outputs/apk/debug/app-debug.apk`。已有安装若需覆盖升级，需要将原私有 `manliu-dev-key.keystore` 放在项目根目录再构建；**密钥不在仓库或 Release 中**，不要上传或公开它。

技术栈：Kotlin、Jetpack Compose、Room、Coil。图集元数据在 Room，图片在应用专属目录。应用不需要账户，也未声明自身网络权限。
